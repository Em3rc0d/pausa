# Pausa 1.6.0

- Removed the fixed three-movement branch for 6–7/10.
- Added explicit region, position, floor and load metadata for 23 existing bilateral/unique movement IDs.
- Ordinary suggestions match the requested region. No unrelated filler when a target/position combination lacks candidates.
- Important discomfort requires a specified affected region plus an explicit request for a general break in other painless regions; affected movement loads are excluded.
- Added memory-only recent-selection ranking, movement-family diversity, another-combination action and persistent-in-tab movement exclusions.
- Added position and avoid-region controls; a limited set of explicit text exclusions is also recognized.
- Ambiguous text requires confirmation. Model-only predictions cannot silently authorize a movement plan.
- Added per-card selection reasons and general reference links; all media remain pending clinical review.
- One- and two-movement plans are valid; no candidates yields a visible abstention. Variation is disabled when no other eligible combination exists.
- Starting rechecks safety and the eligibility of the displayed movement IDs.
- Preserved 112 GIF/poster pairs, local activity identity and absence of model/download infrastructure UI.

Limitations: engineering metadata and intensity thresholds are not clinical validation; repeated movements remain possible when restrictions leave few alternatives; variation history lasts only for the open tab. The optional semantic model still requires physical-device testing.
