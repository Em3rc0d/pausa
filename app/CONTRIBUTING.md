# Contribuir a Pausa

Gracias por ayudar a trabajadores sedentarios a moverse más.

1. Abre un issue con problema reproducible y navegador, sin información de salud personal.
2. Para cambios visuales añade capturas responsive y verificación con teclado.
3. Ejecuta `npm run check` antes de cada pull request.
4. No incorpores recursos ajenos sin licencia verificable y atribuciones requeridas.
5. Para proponer un ejercicio documenta nivel, instrucciones, alternativas, fuentes, criterios para detenerlo y contraindicaciones; requiere revisión clínica antes de publicación como consejo terapéutico.
6. No uses terminología diagnóstica sin evaluación médica.

Se prioriza la accesibilidad, privacidad, simplicidad y fiabilidad por encima de cantidad de ejercicios.

Los gráficos existentes (PNG y GIF) son originales y se regeneran con `scripts_generate_media.py`. No añadas imágenes ni animaciones externas sin documentar titular, licencia y atribución en el PR.
