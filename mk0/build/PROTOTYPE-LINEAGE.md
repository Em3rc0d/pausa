# Linaje del prototipo

Las versiones anteriores se preservan mediante sus changelogs incluidos en app/. No se recrea una historia Git inexistente.

| Etapa | Cambio observado |
|---|---|
| Base | Rutinas, medios iniciales, recordatorios, historial local y biblioteca adicional |
| 1.5 | Sistema visual, navegación y experiencia de formulario |
| 1.6 | Posiciones, exclusiones, familias, motivos y variación |
| 1.7 | Sustitución del clasificador por composición generativa local |
| 1.8 | Escala diferenciada de cansancio/rigidez |
| 1.9 | Propuesta general sin veto automático por una mención habitual de dolor |
| 1.10 | Corrección de rutina de un solo movimiento y legibilidad móvil; cuota de tres posteriormente sustituida |
| 1.11 | Cantidad elegida primero por el modelo; Pausa ágil explícita; selección exacta posterior |

La única copia ejecutable importada es [app/](../../app/README.md). No se duplican árboles binarios por cada versión.
